# CVs

Put the **anonymised** CVs here, one file per person. Supported formats will be decided in the build plan. Word (`.docx`), PDF and text are the expected ones.

- The file name must let the agent link the CV to the team list, e.g. by an ID such as `P017.docx`.
- If a person has several versions, keep only the current one, or put the date in the file name (`P017_2026-03.docx`).
- Don't add identifying details (full name, photo, date of birth, address). These files are committed to the repository.
