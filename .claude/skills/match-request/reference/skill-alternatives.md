# Accepted alternatives and synonyms

Used when triaging "or similar" and when assessing CVs. Extend this list when you disagree with a match: it is the team's shared vocabulary.

- A **synonym** fully satisfies the requirement.
- An **alternative** satisfies "or similar" requirements fully. Otherwise it counts as partly met.

| Requirement | Synonyms (count as met) | Alternatives (similar) |
|---|---|---|
| Kubernetes | K8s, AKS, EKS, GKE, OpenShift | Docker Swarm, Nomad |
| Containers | Docker, Podman, containerd | |
| Cloud | AWS, Azure, GCP, Google Cloud, private cloud, OpenStack | |
| Apache Spark | Spark, PySpark, Spark SQL, Databricks | Flink, Beam, Dask, Snowpark |
| Data pipelines / ETL / ELT | Airflow, Azure Data Factory, dbt, Informatica, SSIS, Talend, NiFi, Glue | Kafka Streams, Fivetran |
| REST APIs / web services | REST, RESTful, OpenAPI, Swagger, SOAP, web services | GraphQL, gRPC |
| Java | Spring, Spring Boot, Jakarta EE, J2EE, Quarkus | Kotlin, Scala (JVM) |
| Python | Django, Flask, FastAPI, pandas | |
| TypeScript / Angular | Angular (2+), AngularJS (partly: outdated), TypeScript | React, Vue, Svelte (for "Angular": partly met) |
| Git workflow | Git, GitHub, GitLab, Bitbucket, Azure DevOps Repos, pull/merge requests, code reviews | SVN (partly) |
| AI tooling in the SDLC | GitHub Copilot, Claude Code, Cursor, Codeium, AI-assisted testing or code review, LLM integration | Machine learning projects (partly) |
| Message brokers (e.g. RabbitMQ) | the named broker, e.g. RabbitMQ | ActiveMQ, Artemis, IBM MQ, Kafka, Azure Service Bus, AWS SQS (partly met unless "or similar") |
| Agile | Scrum, Kanban, SAFe | |
